CS 330 Computational Graphics and Visualization
This repository contains my completed 3D scene and Design Decisions document. The project demonstrates my work with OpenGL, including building objects from basic shapes, applying textures and lighting, and adding camera controls.
How do I approach designing software?
I approach software design by breaking a larger task into smaller parts. For this project, I started with a reference image and identified the basic shapes needed to recreate the objects. I then worked on their size, position, and appearance before adding textures and lighting. This helped me understand how several simple shapes can work together to create a more detailed scene.

The project also helped me develop my spatial design skills. I had to think about proportions, placement, and how objects looked from different angles. In future projects, I can use the same approach of planning the main components first and refining the details as the design develops.
How do I approach developing programs?
I develop programs by making manageable changes and checking the results as I go. While working on the scene, I built the objects first, then added camera movement, textures, and lighting. Keeping these tasks separate made it easier to identify what needed adjusting.

Iteration was a large part of the process. I made changes to object proportions, texture placement, and lighting based on how the scene looked when it ran. Throughout the milestones, I became more comfortable working with the existing project structure and organizing code into functions. I also learned to check how a change affected the whole scene instead of focusing only on one object or feature.
How can computer science help me in reaching my goals?
Computer science gives me the skills to turn an idea into a working application. This project strengthened my understanding of C++, coordinate systems, transformations, and debugging. It also gave me more practice reading existing code and making changes within a larger project. These skills will help me with future coursework and more complex programming assignments.

Professionally, computational graphics has helped me understand how software presents information visually and responds to user input. That knowledge can support my interests in application development, game programming, and data visualization. The project also gave me practice solving problems through small changes and repeated testing, which is an approach I can carry into future development work.
